# Testing and acceptance

Run the public, Fusion-independent tests from the repository root:

```powershell
python -m unittest discover -v
```

These tests inspect semantic TCN geometry rather than byte-for-byte formatting.
They verify stock dimensions, independent profile starts, segment order, exact
arc encoding, closure and profile Z.

## Golden-body acceptance

Do not treat automated tests as CNC validation. For the first production body:

1. Open the body in Fusion and run **Utilities → Export TpaCAD Geometry**.
2. Select SIDE#1, then P0, PX and PY on the same visible occurrence.
3. Confirm every face-derived report row names exactly one Fusion face ID.
4. Confirm reported Z levels against the modeled dimensions.
5. Confirm the shallow T-shaped floor has the modeled negative Z.
6. Confirm there is no separate Z=0 profile for the selected SIDE1 outer loop;
   the mandatory whole-body silhouette is the only finished outer perimeter.
7. Confirm the Z=-1 strip is its own 390 x 11 mm closed rectangle (panel-frame
   X=-350..40 mm, Y=-7..4 mm), even where its boundary coincides with the outer
   silhouette. Confirm the Z=-2 T-shaped floor likewise contains only the full
   trimmed loop of that Fusion face.
8. Confirm the top-facing rebate floor is assigned to SIDE1.
9. Confirm an accessible orthogonal rebate wall is assigned to SIDE3/4/5/6.
10. Confirm an enclosed/ambiguous wall is reported instead of assigned to SIDE1.
11. Export and open the TCN in TpaCAD.
12. Activate every populated SIDE and confirm geometry uses that SIDE's ordinary
   local 2D coordinate system.
13. Click each face-derived contour independently. Selecting one must never
    highlight or apply a setup to geometry owned by another Fusion face.
14. Inspect XI/YI/ZI and every curve in TpaCAD's ASCII view. Every report row
    must correspond to a separate XI/YI profile start.
15. Apply temporary separate setups and confirm there are no bridges.
16. Open/save the file in TpaCAD and compare its semantic geometry.
17. Confirm no setup or machine technology was generated by TribuExporter.

Stop before machine execution if any contour, Z value, stock dimension,
orientation or profile boundary differs from the Fusion body.
