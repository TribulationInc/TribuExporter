# Testing and acceptance

Run the public, Fusion-independent tests from the repository root:

```powershell
python -m unittest discover -v
```

These tests inspect semantic TCN geometry rather than byte-for-byte formatting.
They verify stock dimensions, independent profile starts, segment order, exact
arc encoding, closure and profile Z.

## Golden-body acceptance

Do not treat automated tests as CNC validation. For the first production body:

1. Open the body in Fusion and run **Utilities → Export TpaCAD Geometry**.
2. Select SIDE#1, then P0, PX and PY on the same visible occurrence.
3. Confirm the profile checklist appears after the fourth frame selection.
   Keep only the SIDE1 and lateral regions wanted in this TCN; lateral profiles
   are intentionally unchecked on first discovery.
4. Confirm every face-derived report row names exactly one Fusion face ID and
   that unchecked candidates are absent from the report's write list.
5. Confirm reported Z levels against the modeled dimensions.
6. Confirm the shallow T-shaped floor has the modeled negative Z.
7. Confirm there is no separate Z=0 profile for the selected SIDE1 outer loop;
   the mandatory whole-body silhouette is the only finished outer perimeter.
8. Confirm the Z=-1 strip is its own 390 x 11 mm closed rectangle (panel-frame
   X=-350..40 mm, Y=-7..4 mm), even where its boundary coincides with the outer
   silhouette. Confirm the Z=-2 T-shaped floor likewise contains only the full
   trimmed loop of that Fusion face.
9. With **Suppress SIDE1 Z=0 loop when identical deeper loop exists** enabled,
   confirm the Z=0 T boundary is listed as serializer-suppressed and only its
   geometrically identical deeper T profile is written. Confirm the mandatory
   finished silhouette remains present.
10. Confirm the top-facing rebate floor is assigned to SIDE1.
11. Explicitly enable one wanted lateral region, export, reopen the command and
    confirm that choice is restored. New lateral geometry must remain off.
12. Confirm an accessible orthogonal rebate wall is assigned to SIDE3/4/5/6.
13. Confirm an enclosed/ambiguous wall is reported instead of assigned to SIDE1.
14. Export and open the TCN in TpaCAD.
15. Activate every populated SIDE and confirm geometry uses that SIDE's ordinary
   local 2D coordinate system. On SIDE3-SIDE6, confirm bottom is local Y=0,
   top is local Y=DS, and stock allowance remains a negative inward local Z.
16. Click each face-derived contour independently. Selecting one must never
    highlight or apply a setup to geometry owned by another Fusion face.
17. Inspect XI/YI/ZI and every curve in TpaCAD's ASCII view. Every report row
    must correspond to a separate XI/YI profile start.
18. Apply temporary separate setups and confirm there are no bridges.
19. Open/save the file in TpaCAD and compare its semantic geometry.
20. With native holes disabled, confirm no setup or machine technology was
    generated by TribuExporter.

## Fictive-face acceptance

1. Select one exposed planar inclined face in **Fictive faces (SIDE7+)**.
2. Confirm the report assigns it SIDE7 and records exactly one source face ID.
3. Select the same set in a different click order and confirm SIDE numbering is
   unchanged.
4. In TpaCAD, confirm SIDE7 is additional to the six real faces and opens as an
   ordinary programmable face.
5. Confirm every loop belonging to the selected BRepFace appears as an
   independently started closed profile at local Z=0.
6. Inspect the `GEO` section and confirm SIDE7 has explicit P0/P1/P2 and face
   thickness.
7. Reconstruct each local boundary point through the serialized SIDE7 frame and
   compare it with the Fusion face. Plane and boundary error must remain within
   the declared export tolerance; no endpoint may be moved to achieve closure.
8. Repeat with two selected slopes and confirm they become SIDE7 and SIDE8,
   never one merged face.
9. Repeat with a plane rotated in panel XY, not only a simple Z bevel.
10. Confirm no SETUP, tool orientation, roughing, saw/blade instruction or
    compensation was generated.

Stop before machine execution if any contour, Z value, stock dimension,
orientation or profile boundary differs from the Fusion body.

## Native-hole acceptance

1. Keep **Export native Fusion simple blind holes (W#81 CAM)** off and confirm
   the same body exports no W#81 records.
2. Enable it on the dedicated Fusion hole test body.
3. Confirm only native simple blind `HoleFeature` objects are listed. The five
   visually hole-like openings that were not made with HoleFeature must not
   appear as hole workings.
4. Confirm every accepted feature names one entry BRep face and one real or
   selected fictive SIDE.
5. On SIDE1 and every lateral/fictive side, verify local X/Y against Fusion,
   negative Z against the modelled endpoint, and diameter against the native
   feature parameter.
6. Confirm a native hole entered from SIDE2 is reported and omitted under the
   current V1 scope.
7. Confirm Through All, counterbore, countersink, tapped, clearance, and
   ambiguous-entry features are reported and omitted.
8. Confirm a Fusion Feature Pattern of an existing hole does not create extra
   W#81 records. Its final BRep boundaries may appear as optional profiles and
   must remain independently deselectable.
9. Pattern sketch points, create one native simple blind HoleFeature from all
   resulting points, and confirm one W#81 record is emitted per position.
10. Inspect the ASCII record: it must be `W#81 ::WTp`, absolute (`#8015=0`),
   and contain machine/group, X, Y, negative depth, diameter and drill type.
   It must never contain `#205`.
11. Reopen the exporter and confirm the opt-in checkbox state is restored only
   after a successful prior export.
12. Open/save in TpaCAD, compare semantic coordinates, run normal simulation,
    and stop before CNC execution if any side, center, depth, or diameter is
    unexpected.
